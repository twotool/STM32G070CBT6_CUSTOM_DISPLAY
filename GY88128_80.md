# GY88128-80 UPS Segment LCD Driver

## Overview

This project uses a custom **GY88128-80** segment LCD display for UPS status visualization, driven by the **HT1621** LCD controller IC.

## Hardware Interface

### LCD Controller: HT1621
- Communication: 3-wire serial (CS, WR, DATA)
- Configuration: 1/3 bias, 1/4 duty (4 commons)
- RAM: 16 bytes (128 bits) for segment control

### GPIO Pin Assignments

| Signal | Port | Pin |
|--------|------|-----|
| `HT1621_CS` | GPIOA | PA0 |
| `HT1621_WR` | GPIOA | PA1 |
| `HT1621_DATA` | GPIOA | PA2 |
| `SYSTEM_LED` | GPIOC | PC13 |

---

## Display Layout

### Numeric Display
- **6 digits** with 7-segment displays
- Digits 1-3: Input side (voltage, frequency, battery)
- Digits 4-6: Output side (voltage, frequency, load)

### Status Segments (S1-S33)

| Segment | Function |
|---------|----------|
| S1 | INPUT indicator |
| S2 | BATTERY indicator |
| S4 | LOAD indicator |
| S5 | VDC symbol |
| S6 | INPUT HZ symbol |
| S7 | VAC symbol |
| S8 | OUTPUT indicator |
| S13 | KW symbol |
| S14 | OUTPUT HZ symbol |
| S16 | Fault/Overload indicator |
| S17-S21 | Load level bars |
| S23 | Backlight control (via IRQ pin) |
| S29-S33 | Battery level bars |

## Internal Structure

### Segment Mapping
The driver uses a lookup table `segment_map[34][2]` that maps segment numbers (S1-S33) to HT1621 RAM addresses and bit positions:
- `{address, bit}` pairs calculated from pin and COM assignments

### Digit Mapping
The `digit_map[6][7][2]` array maps each digit's 7 segments (A-G) to RAM locations:
- 6 digits × 7 segments × (address, bit)

### HT1621 Commands Used

| Command | Value | Purpose |
|---------|-------|---------|
| `SYS_EN` | 0x01 | Enable system oscillator |
| `LCD_ON` | 0x03 | Turn on LCD bias |
| `RC256K` | 0x18 | Use internal RC oscillator |
| `BIAS13_COM4` | 0x29 | 1/3 bias, 4 commons |

## Usage Example

```c
#include "GY88128_80_UPS_SEGMENT_LCD_DRIVER.h"

int main(void) {
    HAL_Init();
    // ... GPIO and system init ...
    
    lcd_init();           // Initialize LCD
    clear_all();          // Clear display
    
    // Display values
    input_vac_display(220);       // Show 220V input
    output_VAC_display(230);      // Show 230V output
    battery_VDC_display(24.5f);   // Show 24.5V battery
    load_KW_display(1.5f);        // Show 1.5 KW load
    
    // Show status
    line_mode_display();          // Indicate line mode
    battery_level_display(25.0f, 28.0f, 21.0f);  // Show battery bars
    load_level_display(750.0f, 1500.0f, 0.0f);   // Show load bars
}
```
